# Prince Edward Island — Interactive Presentation

A static, animated slide-show website built for GitHub Pages. The interactive PEI population chart is on **slide 4**.

## Run locally

Open `index.html` in a modern browser. No build tools, package installation, or server are required.

## Publish on GitHub Pages

1. Create a GitHub repository (or open the repository where you want the presentation).
2. Unzip this archive and upload **the contents of this folder** to the top level of the repository. `index.html` must be in the repository root, beside the `assets` folder.
3. Commit the uploaded files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. After GitHub Pages deploys the site, use the **Visit site** link on the Pages settings screen.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Controls

- `←` / `→` or `Space`: previous / next slide
- `Home` / `End`: first / last slide
- `F`: fullscreen
- `Overview`: jump directly to any slide
- Slide 4 population chart: click the All / 10Y / 25Y / 50Y / 100Y filters, hover or tap the graph for a year/population tooltip, drag across the graph to zoom, and double-click or press Reset view to return to the full range.

## About the slides

The website preserves every content-bearing slide from the uploaded PowerPoint and adds the interactive chart as slide 4. The uploaded source also contained blank placeholder slides (16–27 and 29–46); those blank pages are not included in the website navigation. The original PowerPoint's “Economy and Natural Resources” section slide and Sources slide are retained.

The chart uses the population time series and wording in the user-provided HTML. Its source note states that values between census years are interpolated and the July 1, 2026 population estimate is preliminary. Please verify or update the figures before public use if needed.
